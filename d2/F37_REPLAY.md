# Independent f37 theorem replay

This directory contains two native, from-definition CAS replays of the f37
pre-resultant elimination theorem. Neither replay reads a serialized polynomial,
a generated factor file, the old Singular input, a pickle, or the existing
membership certificate.

## Exact claim and scope

Let

```
I = <G1, G2, G3, G5body + Phi>
    in QQ[d2,d1,d0,dm1,dm2,dm3,dm4,Phi].
```

The replay checks all of the following over `QQ`:

1. The elimination ideal

   ```
   I intersect QQ[d2,d1,d0,dm1,Phi]
   ```

   is principal.
2. Its generator is equal up to a nonzero rational scalar to the independently
   regenerated degree-31 factor `f31`.
3. That same `f31` lies in `I` (its normal form modulo a Groebner basis of `I`
   is zero).

Thus every solution of the pre-resultant system over a `QQ`-algebra satisfies
`f31 = 0`. This is a characteristic-zero / `QQ` statement. The separately
kernel-checked integer membership certificate has denominator-clearing
multiplier

```
D = 46875 = 3 * 5^6.
```

Consequently that certificate cannot be divided by `D` in characteristics 3
or 5. This replay makes no uniform claim in those characteristics. Its stated
scope is exactly `QQ` and base change to `QQ`-algebras.

## What defines the system

The mathematical input is the formal t=4 series

```
S = 1 + d2*u^2 + d1*u^3 + d0*u^4
      + sum(k=1..13, dm[k]*u^(4+k)).
D2(k) = coefficient(S^2, u^(8+k)).
D3(j) = coefficient(S^3, u^(12+j)).
```

The linear phase successively imposes `D2(k)=0` and solves for the fresh
variable in these pairs:

```
(k,target) = (1,dm5), (2,dm6), (3,dm7), (4,dm8),
             (5,dm9), (6,dm10), (7,dm11), (9,dm13).
```

After those substitutions, the pre-resultant generators are reconstructed as

```
G1      = D3(1)
G2      = D3(2)
G3      = D3(3)
G5body  = D3(5)
G5      = G5body + Phi.
```

The sources used to identify and audit that definition were:

- `F37_SATURATION_REPORT.md`: the theorem, the four small equations, the
  elimination target, the 102-term/degree-31 diagnostic, and the multiplier
  `D = 46875` with its field-scope warning.
- `FULL_SYSTEM_BRIDGE.md`, section 1: the variable dictionary
  `dm1=e, dm2=r, dm3=s, dm4=d_-4`, the rational-coefficient form of the four
  equations, and the role of `Phi`.
- `regenerate_system.py`: the formal-series coefficient rule, the exact eight
  linear `D2` slices, the four retained `D3` slices, and the historical
  resultant order. The new scripts re-express this recipe independently in
  native Macaulay2 and native Sage; they do not execute or import that Python
  file.
- `system_generators.py`: the variable order and the status of
  `generators.json` as a canonical reference derived from the old pickle. It is
  used only by `f37_replay_selftest.py` on the reference side of the local
  comparison. It is not imported or read by either CAS replay.
- `paper_src/upstream_facts.json`: upstream provenance for arXiv:2204.14178,
  including the `(8,28)` bracket case, the common-root template, and the
  induction/recursion markers. It provides the paper-level envelope but does
  not supply a serialized G-system or any terms consumed by the replay.

As an indexing sanity check, both CAS scripts also reconstruct the published
t=3 checkpoint

```
coefficient(S3^2,u^7) = 2*d0*dm1 + 2*d1*dm2 + 2*dm4.
```

## How f31 is regenerated independently

The scripts do not contain the 102 terms of `f31`. Starting from their newly
constructed `G` polynomials, they eliminate `dm4` by the denominator-cleared
combinations

```
H2 = dm1*G2 - dm2*G1
H3 = dm1*G3 - dm3*G1
H5 = dm1*(G5body+Phi)
     + (d0*dm1+d1*dm2+d2*dm3)*G1.
```

They then compute

```
RA = resultant_dm3(H2,H3)
RB = resultant_dm3(H2,H5),
```

factor each, and select its unique factor involving `dm2`. Calling those
factors `A` and `B`, they compute and factor

```
resultant_dm2(A,B).
```

`f31` is selected intrinsically as the unique factor that both involves `Phi`
and has total degree 31. The scripts then compute the true Groebner elimination
ideal directly from `I`; this is a separate route from the resultant chain.
They compare the principal ideals generated by the two outputs, so arbitrary
nonzero rational normalization is ignored.

This gives two independent paths inside each replay:

```
formal-series construction -> G-system -> Groebner elimination generator
                                      \
                                       -> classical resultant chain -> f31
```

Equality of the two principal ideals is check (2), while direct normal-form
reduction of resultant-derived `f31` modulo the original four-generator ideal
is check (3).

## Running Macaulay2 under WSL

From a WSL shell, after installing Macaulay2:

```bash
cd d2
M2 --script f37_replay_m2.m2
```

The script uses Macaulay2's `Elimination` package, univariate Sylvester
resultants, polynomial factorization over `QQ`, and a Groebner elimination
order. A successful run ends with these lines (possibly separated by `INFO`
lines):

```text
PASS: (a) elimination ideal in (d2,d1,d0,dm1,Phi) is principal
PASS: (b) its generator equals independently reconstructed f31 up to a QQ unit
PASS: (c) independently reconstructed f31 lies in the pre-resultant ideal
PASS: f37 theorem replay complete over QQ
```

## Running Sage under WSL

From the same directory, after installing SageMath:

```bash
sage f37_replay_sage.py
```

Sage performs its native polynomial/resultant/factor operations and uses its
Singular-backed Groebner ideal implementation. The three theorem `PASS` lines
and final completion line have the same wording as the Macaulay2 replay.

## Local construction self-test

The available Windows Python/SymPy environment can test generator construction,
but it is not presented as the external CAS replay:

```powershell
cd d2
python .\f37_replay_selftest.py
```

`f37_replay_selftest.py` first rebuilds the system with its own coefficient
convolution and linear substitutions. Only afterward does it load
`generators.json` through `system_generators.py` and compare exact expressions.
It checks the t=3 indexing checkpoint; `G1`, `G2`, `G3`, and `G5body`; the two
cleared intermediate polynomials `H2`, `H3`; and the rational solution `sol4`.
