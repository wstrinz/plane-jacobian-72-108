## Why 550 is unreachable here (unconditional, independent of any C-series step)

The degree of the forcing divisor factorises as

```
deg Phi = deg f + N * deg C = 14 + N * a_0 .
```

`deg C = a_0` is the first coordinate of the corner: `a_0 = 8` for `(8,28)`, but
`a_0 = 5` for `(5,20)`. So on this corner `deg Phi = 14 + 5N` is `= 4 (mod 5)`, and

```
deg Phi = 550  =>  N = (550 - 14)/5 = 536/5,  NOT an integer.
```

**No integer tower length `N` can produce 550 at this corner.** The `a`-only prediction
fails on divisibility grounds before any choice of `N`. The residual is not "a is the
wrong variable by a little" — the corner's `a_0` sets the whole scale. `deg f = 14`
happens to coincide with the `(108,144)` case, but `deg C` does not.

Likewise `mult_(y+1) Phi = e + N` where `e = b-a+1`. Here `b-a = 2` (non-adjacent), so
`e = 3` versus `e = 2` on the `(8,28)` corner: even the *constant* in "tower length plus
a constant" changed, before `N` is chosen.

### Forcing ODE (the parametric family, unspecialised)

The same operator identity as corner-144, `[P, x^s f/c^b] = x^kappa`, i.e.

```
a { t c f' - [t(b-a)+kappa+1] c' f } = c^(b-a+1) .
```

At `(a,b,t,kappa) = (3,5,5,3)`:

```
15 c f' - 42 c' f = c^3 ,          c = C = y^2 (y^3+1) ,   v(F) = s = -11 .
```

(`corner144_verify`-style direct differentiation of the bracket confirms this general

### Solving it

Local orders force `f = A y^5 g^3` with `c = y^2 g`, `deg g = a_0 - q = 3`,
`g(0) != 0`, `g(-1) = 0`. The balance is `rho = (e-1)mu + 1` with `e = 3`: `rho = 5` at
the order-2 root `y=0`, `rho = 3` at each simple root. The `y=infinity` leading
coefficient `15d - 42*5` is resonant exactly at `deg f = 14`. Substitution collapses the
whole ODE to

```
3A (y g' - 3 g) = 1 .
```

The coefficients force `g_1 = g_2 = 0`, the `y^3` term is resonant (free), and
`g(-1)=0` forces `g_0 = g_3`. Monic normalisation gives the forced solution

```
g   = y^3 + 1 = (y+1)(y^2 - y + 1) ,      H_2 = y^2 - y + 1  (separable, avoids 0,-1),
C   = y^2 (y^3 + 1) ,
f   = -(1/15... )  ->  f = -(1/9) y^5 (y^3 + 1)^3 ,     A = -1/9 .
```

`H_2 = y^2 - y + 1` is the forced cyclotomic-type residual — the exact analogue of the
`(108,144)` result `h_4 = y^4-y^3+y^2-y+1`, `g = y^5+1`. In general `g = y^{a_0-q} + 1`.
An independent 15-variable linear solve returns `f` as the unique polynomial solution of
degree `<= 14` (check E).

## What the b-dependence actually is (three data points, stated honestly)

With the third point the invariants resolve into closed forms in the FULL parameter set
`(a, b, t, kappa, a_0, q)` — not in `a` alone. Writing `e = b-a+1`,
`N = a[t(a+b)-(kappa+1)] - 2b`:

```
deg Phi        = (e a_0 - q + 1) + N a_0
ord_y Phi      = ((e-1) q + 1)  + N q
mult_(y+1) Phi = e + N
cofactor       = r (e + N) ,      r = a_0 - q - 1 .
```

These reproduce **all three** points exactly:

| case | corner | `(a,b)` | `t,kappa` | `(a_0,q,e,N)` | `(deg, ord_y, mult, cof)` |
|---|---|---|---|---|---|
| `(72,108)` | `(8,28)` | `(2,3)` | `4,2` | `(8,7,2,28)` | `(238,204,30,4)` * |
| `(108,144)` | `(8,28)` | `(3,4)` | `4,2` | `(8,3,2,67)` | `(550,205,69,276)` |
| **`(75,125)`** | **`(5,20)`** | **`(3,5)`** | **`5,3`** | **`(5,2,3,98)`** | **`(504,201,101,202)`** |

`*` `(72,108)` is the `r=0` (full-multiplicity) degenerate case: the pure ansatz degree
`e a_0 - q + 1 = 10` falls short of the resonant degree `14`, so `f` picks up an EXTRA
quartic unit cofactor `q_4` (the "residual place lives in `f`, power 1" story). The other

This is the resonance-gap distinction, orthogonal to the `a`-only question.

**Underdetermination, stated plainly.** Three points cannot separate all of
`(t, kappa, a_0, q)` — they are correlated along the two corners used (`t=4,kappa=2` twice;
`t=5,kappa=3` once). The formulas above are the honest general fit; a fourth corner

of the correlation. But the `a`-only hypothesis is already dead: it predicts `550`, a
degree this corner cannot represent for any integer `N`.
